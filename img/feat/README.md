# 特色說明照片（八個節點共用一組，不分車款）
- 檔名固定：hd（頭管標）、bowl（上碗組）、tt（上管標）、st（中管標）、clamp（座管束）、dt（下管標）、bb（BB）、dropout（後勾爪），副檔名 .webp。
- 規格：1:1、800×800 px、WebP、單張建議 ≤120 KB。主體置中，四邊留 10% 以上邊距。構圖角度對齊 3D 特寫。
- 換照片：覆蓋同名檔，並把 `data/feat.json` 對應節點的 `"ph": true` 改成 `false`（或刪掉該欄），圖說就會從「實景參照（佔位）」變成「實景照片」。
- 文案：改 `data/feat.json` 的 `sub`（副標）與 `body`（段落陣列）。
- 母檔（原始高解析照片）放 Drive，不放此處。
