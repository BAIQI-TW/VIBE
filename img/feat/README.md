# 特色說明照片與文案（八個節點；上管標、下管標依車款）
- 節點代碼（檔名與 `data/feat.json` 的鍵一致）：hd（頭管標）、bowl（上碗組）、tt（上管標）、st（中管標）、clamp（座管束）、dt（下管標）、bb（BB）、dropout（後勾爪），副檔名 .webp。
- 規格：1:1、800×800 px、WebP、單張建議 ≤120 KB。主體置中，四邊留 10% 以上邊距。構圖角度對齊 3D 特寫。
- 換照片：覆蓋同名檔，並把 `data/feat.json` 對應節點的 `"ph": true` 改成 `false`（或刪掉該欄），圖說就會從「實景參照（佔位）」變成「實景照片」。
- 文案：改 `data/feat.json` 的 `sub`（副標）與 `body`（段落陣列）。兩者皆為 `{"tw":…,"en":…}`；`en` 留空（`""` 或 `[]`）時，EN 模式退回顯示中文，不會報錯。節點顯示名稱（標題）仍走 i18n 詞庫。
- **快取**：覆蓋圖檔或改 JSON 之後，必須重跑 `node tools/stamp.mjs <多檔資料夾>`（發布流程本來就會跑）。它把 `feat.json` 與全部照片的內容雜湊寫進 `index.html` 的 `<meta name="vibe-feat">`，app 以此為 `feat.json` 與照片網址加 `?h=`，瀏覽器才會重抓。
- 鍵不認得（例如打錯代碼）：app 不套用該筆，並在 console 印出「feat.json：app 不認得的鍵…」與有效鍵清單。
- 母檔（原始高解析照片）放 Drive，不放此處。
- **依車款／多張（v199zzzzzz123）**：`img` 可寫成網址、網址陣列（多張，點圖換下一張、循環），或依車款的物件 `{"64":…,"325":…,"audax":…,"ili":…,"ss":…,"ex":…,"*":預設}`（值可為網址或陣列）。依車款取到＝「實景照片」；沒有該車款而落到 `*`＝「實景參照（佔位）」。目前上管標 `tt_<車款>.webp` 六款齊；下管標 `dt_<車款>.webp` 缺 AUDAX（退回佔位）。
- 鈦零組件加購照片在 `img/addon/`（fork、stem_01／02、post、collar、crank_01／02），對應表在 `js/app.js` 的 `ADD_IMG`；加購開啟時顯示，多張點圖循環。
