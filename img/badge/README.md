# 車款標（車型小卡橫幅標誌）
- 來源：使用者 2026-11-20 提供的六個車款標 SVG（CorelDRAW 匯出），已去掉 XML 宣告、DOCTYPE、metadata，只留 viewBox 與單一 path。
- 對應（`js/app.js` 的 `MC_IMG`，鍵＝車型小卡上的車款名）：m64＝MASTER 64Ti、m325＝MASTER 325Ti、audax＝AUDAX 325Ti、ili＝ili ili 325Ti、ss＝ili ili SS-2205、ex＝ili-ili EX 325Ti。
- 顯示方式：CSS mask，顏色取文字色（明暗主題自動切換），圖內的填色不影響顯示；小卡比例 3:1、置中等比縮放。
- 換圖：覆蓋同名檔即可；只認 path 的形狀（透明＝不顯示）。
